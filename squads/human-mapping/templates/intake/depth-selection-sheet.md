# Depth Selection Sheet

> Instrucoes: Selecione o nivel de profundidade adequado para esta sessao de assessment. Considere o objetivo, tempo disponivel e instrumentos disponiveis.

## Opcoes de Profundidade

### /fast — Mapeamento Rapido (~30 minutos)
- **Layers cobertas:** Traits + Types + Motivation
- **Nivel de detalhe:** Visao geral, sem facetas detalhadas
- **Frameworks minimos:** Big Five + 1 tipologia + 1 motivacao
- **Output:** Executive Snapshot (1 pagina)
- **Ideal para:** Triagem rapida, primeira impressao estruturada, hiring screening

### /start — Mapeamento Standard (~60 minutos)
- **Layers cobertas:** Todas as layers (Traits, Types, Motivation, Strengths, Team Role, Career, Action)
- **Nivel de detalhe:** Standard, com principais facetas
- **Frameworks minimos:** 2+ frameworks por layer
- **Output:** Perfil completo + Executive Snapshot
- **Ideal para:** Assessment de desenvolvimento, coaching inicial, team building

### /deep — Mapeamento Profundo (~90 minutos)
- **Layers cobertas:** Todas as layers + Contradiction analysis + Development planning
- **Nivel de detalhe:** Profundo, todas as facetas + cross-framework validation
- **Frameworks minimos:** 3+ frameworks por layer com convergencia
- **Output:** Deep Persona Report completo + Development Plan
- **Ideal para:** Leadership assessment, decisoes criticas de hiring, sucessao

## Tabela de Trade-offs

| Criterio | /fast | /start | /deep |
|---|---|---|---|
| Tempo necessario | ~30 min | ~60 min | ~90 min |
| Instrumentos minimos | 3 | 5-7 | 8+ |
| Confidence esperada | 0.5-0.7 | 0.7-0.85 | 0.85-0.95 |
| Contradicoes analisadas | Nao | Parcial | Completo |
| Plano de desenvolvimento | Nao | Basico | Detalhado |
| Calibracao de qualidade | Basica | Standard | Rigorosa |
| Custo relativo | Baixo | Medio | Alto |
| Risco de erro | Maior | Moderado | Menor |
