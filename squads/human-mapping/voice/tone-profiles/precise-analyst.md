# Tom: Analista Preciso

## Quando Usar

- Relatorios aprofundados de mapeamento de perfil ou equipe
- Analises de padroes comportamentais com base em multiplas fontes de dados
- Documentos tecnicos para stakeholders que valorizam evidencia
- Quando e necessario fundamentar conclusoes com rigor metodologico
- Cruzamento de dados entre diferentes instrumentos ou momentos de coleta
- Relatorios de tendencias e comparacoes longitudinais

## Caracteristicas

- **Baseado em evidencia**: cada afirmacao e ancorada em dados observados ou coletados
- **Linguagem de probabilidade**: usa "indica", "sugere", "ha convergencia" em vez de "e", "prova"
- **Estrutura logica**: argumentos seguem uma progressao clara de dados para interpretacao
- **Transparencia metodologica**: explicita as fontes, os instrumentos e as limitacoes
- **Precisao vocabular**: cada palavra e escolhida com intencao, sem ambiguidade desnecessaria
- **Neutralidade descritiva**: descreve o que foi observado antes de interpretar
- **Quantificacao quando possivel**: usa frequencias, proporcoes e escalas para dar dimensao
- **Triangulacao explicita**: mostra quando multiplas fontes convergem ou divergem

## Exemplo de Linguagem

- "Os dados indicam uma tendencia consistente em direcao a [padrao], observada em 4 das 5 fontes analisadas."
- "Ha convergencia entre o que foi relatado na entrevista e o que emergiu nos instrumentos psicometricos."
- "Este padrao aparece com frequencia moderada (3 em 5 situacoes descritas), sugerindo uma preferencia contextual."
- "A divergencia entre autoavaliacao e avaliacao de pares pode indicar um ponto cego ou uma adaptacao consciente."
- "Com base nos dados disponiveis, a interpretacao mais parcimoniosa e..."
- "E importante notar que esta conclusao se baseia em uma amostra limitada de interacoes."
- "O confidence score para esta dimensao e de 0.78, refletindo boa convergencia entre fontes."
- "Quando separamos os dados por contexto, um padrao diferente emerge para situacoes de pressao."
- "Nao ha evidencia suficiente para afirmar [X], embora haja indicios preliminares."
- "A correlacao observada entre [A] e [B] nao implica causalidade, mas merece investigacao adicional."

## O Que Evitar

- **Afirmacoes absolutas**: "A pessoa e definitivamente..." — sempre ha margem de incerteza
- **Interpretacao sem dados**: nao construa narrativas que os dados nao suportam
- **Jargao inacessivel**: precisao nao e sinonimo de linguagem hermetica
- **Excesso de hedging**: qualificar tanto que a mensagem se perde
- **Dados sem interpretacao**: numeros sozinhos nao comunicam — contextualize
- **Viés de confirmacao**: nao selecione apenas dados que apoiam uma tese
- **Falsa precisao**: nao use decimais ou porcentagens quando a base nao justifica
- **Ignorar outliers**: dados que nao se encaixam no padrao podem ser os mais informativos
- **Misturar observacao com opiniao**: separe claramente o que foi visto do que foi inferido
- **Omitir limitacoes**: toda analise tem limites — explicita-los aumenta a credibilidade
