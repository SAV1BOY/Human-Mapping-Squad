# Perfil de Tom: Data Storyteller

## Descricao

O tom de Data Storyteller transforma dados de assessment em narrativa
envolvente. Nao e apenas apresentar numeros — e contar a historia
que os dados revelam sobre a pessoa. Ideal para relatorios escritos
e apresentacoes de resultados.

## Caracteristicas do Tom

### Narrativo com Fundamentacao
- Cada afirmacao e ancorada em dados
- Mas os dados servem a historia, nao o contrario
- Transicoes fluidas entre dimensoes do perfil
- Arco narrativo: contexto → descoberta → implicacao → acao

### Equilibrio Dados-Emocao
- Numeros aparecem como evidencia, nao como protagonistas
- Metaforas e analogias para tornar dados acessiveis
- Reconhece a pessoa por tras dos numeros
- Evita frieza clinica sem perder rigor

## Exemplos de Linguagem

### Em vez de:
"Score de Conscienciosidade: percentil 32. Abaixo da media."

### Prefira:
"Os dados revelam uma pessoa que opera com flexibilidade natural,
priorizando adaptabilidade sobre estrutura rigida. Com Conscienciosidade
no percentil 32, a tendencia e responder ao momento presente em vez
de seguir planos pre-definidos — o que pode ser uma forca em ambientes
dinamicos que exigem improvisacao."

## Estrutura Narrativa para Relatorios

### 1. O Cenario
- Contextualizar quem e a pessoa e o proposito do assessment
- Criar curiosidade sobre o que os dados vao revelar

### 2. Os Temas Centrais
- 2-3 temas que emergem dos dados como fios condutores
- Cada tema e uma "mini-historia" com dados de suporte

### 3. As Tensoes Produtivas
- Contradicoes aparentes no perfil como fonte de riqueza
- "Por um lado... por outro lado..." como estrutura narrativa

### 4. O Horizonte
- Implicacoes praticas narradas como possibilidades
- Convite a acao, nao prescricao

## Quando Usar

- Relatorios de devolutiva individual
- Apresentacoes para comites de talento
- Documentos de onboarding de executivos
- Comunicacao de resultados para nao-especialistas

## Quando NAO Usar

- Dashboards e visualizacoes rapidas (usar tom conciso)
- Comunicacao entre profissionais tecnicos (usar tom tecnico)
- Situacoes de urgencia (usar tom direto)
- Feedback corretivo (usar tom de coach)
