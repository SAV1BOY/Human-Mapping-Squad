# Checklist: Qualidade da Avaliacao de Tracos

## Proposito
Verificar que os tracos de personalidade foram medidos com confianca suficiente, que o Big Five foi completado integralmente e que a verificacao cross-framework foi realizada para validar os resultados.

## Criterios de Aprovacao

### Obrigatorios (todos devem passar)
- [ ] Todos os cinco fatores do Big Five foram avaliados — Evidencia: `scores para O, C, E, A, N registrados`
- [ ] Cada fator possui score de confianca individual acima do limiar minimo — Evidencia: `confianca por fator >= limiar`
- [ ] Facetas de cada fator foram exploradas com profundidade minima — Evidencia: `pelo menos 2 facetas por fator avaliadas`
- [ ] Verificacao cross-framework foi executada com pelo menos um framework adicional — Evidencia: `resultado de cross-check registrado`
- [ ] Convergencia entre frameworks foi verificada — Evidencia: `grau de convergencia calculado`
- [ ] Divergencias significativas entre frameworks foram sinalizadas — Evidencia: `lista de divergencias documentada ou vazia`
- [ ] Evidencia comportamental sustenta cada traco principal identificado — Evidencia: `pelo menos 1 exemplo por fator`
- [ ] Nenhum fator foi inferido apenas por auto-relato sem corroboracao — Evidencia: `registro de fontes multiplas`
- [ ] Perfil de tracos e consistente com o padrao geral de respostas — Evidencia: `analise de coerencia aprovada`

### Desejaveis (aumentam confianca)
- [ ] Tres ou mais frameworks foram utilizados para cross-check
- [ ] Nuances contextuais dos tracos foram documentadas (ex: extroversao no trabalho vs vida pessoal)
- [ ] Intensidade dos tracos foi graduada (nao apenas presente/ausente)
- [ ] Estabilidade temporal dos tracos foi considerada
- [ ] Comparacao com normas populacionais foi incluida

## Evidencia Necessaria
- Scores completos do Big Five com valores numericos ou faixas
- Score de confianca individual por fator
- Resultado de cross-check com framework adicional
- Grau de convergencia entre frameworks
- Lista de divergencias identificadas (se houver)
- Exemplos comportamentais por fator
- Registro de fontes de evidencia utilizadas

## Acao se Falhar
- Se algum fator do Big Five esta ausente: completar avaliacao do fator faltante
- Se confianca de algum fator esta baixa: coletar mais evidencia para o fator especifico
- Se cross-framework nao foi feito: executar verificacao com framework adicional
- Se divergencias nao foram sinalizadas: revisar e documentar divergencias
- Se falta evidencia comportamental: coletar exemplos adicionais do respondente
- Avaliacao de tracos nao pode ser aprovada sem Big Five completo e cross-check realizado

## Agente Responsavel
- **Agente principal**: Agente de Tracos de Personalidade
- **Agentes de suporte**: Agente de Cross-Framework
- **Aprovador final**: Agente de Qualidade
