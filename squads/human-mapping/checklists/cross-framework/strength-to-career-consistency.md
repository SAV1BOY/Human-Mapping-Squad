# Checklist: Consistencia Forcas para Carreira

## Proposito
Verificar que as forcas mapeadas (CliftonStrengths, VIA, Belbin) sao consistentes com as recomendacoes de carreira (RIASEC, Kolbe), garantindo que o perfil de forcas sustenta a direcao de carreira proposta.

## Criterios de Aprovacao

### Obrigatorios (todos devem passar)
- [ ] Dominio CliftonStrengths dominante comparado com tipo RIASEC — Evidencia: `analise dominio Clifton vs codigo Holland com concordancia`
- [ ] Forcas top 5 Clifton compativeis com demandas da carreira sugerida — Evidencia: `matriz forcas x demandas de carreira`
- [ ] Papel Belbin compativel com tipo de funcao sugerida — Evidencia: `comparacao Belbin role vs tipo de funcao recomendada`
- [ ] Perfil Kolbe compativel com modo de trabalho da carreira — Evidencia: `analise Kolbe x demandas operacionais da carreira`
- [ ] Forcas de carater VIA alinhadas com cultura tipica da carreira — Evidencia: `comparacao VIA x valores tipicos do setor/funcao`
- [ ] Carreiras sugeridas aproveitam forcas naturais (nao exigem fraquezas) — Evidencia: `verificacao: forcas top 5 sao uteis, bottom 5 nao sao criticas`
- [ ] Gaps de forca para carreira desejada foram quantificados — Evidencia: `lista de gaps com severidade e plano de mitigacao`
- [ ] Forcas diferenciadores (unicas no contexto de carreira) foram identificadas — Evidencia: `lista de forcas que sao vantagem competitiva`

### Desejaveis (aumentam confianca)
- [ ] Satisfacao em experiencias passadas foi correlacionada com uso de forcas
- [ ] Carreiras alternativas que aproveitam as mesmas forcas foram listadas
- [ ] Tendencias de mercado para as forcas do respondente foram consideradas
- [ ] Potencial de crescimento via forcas foi estimado

## Evidencia Necessaria
- Analise dominio Clifton vs codigo Holland
- Matriz forcas x demandas de carreira
- Comparacao Belbin e Kolbe vs funcao
- Comparacao VIA vs cultura do setor
- Lista de gaps com plano de mitigacao
- Forcas diferenciadoras

## Acao se Falhar
- Se forcas e carreira nao combinam: revisar recomendacao de carreira ou sinalizar gap critico
- Se gaps sao severos: avaliar viabilidade de desenvolvimento ou propor carreira alternativa
- Se Belbin e Kolbe conflitam com funcao: investigar se funcao real permite adaptacao
- Se forcas diferenciadoras nao foram identificadas: analisar perfil buscando combinacoes unicas

## Agente Responsavel
- **Agente principal**: Agente de Cross-Framework
- **Agentes de suporte**: Agente de Forcas, Agente de Carreira
- **Aprovador final**: Agente de Qualidade
