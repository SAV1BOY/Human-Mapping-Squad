# Checklist: Consistencia Tipos para Motivacoes

## Proposito
Verificar que os tipos identificados (MBTI, DISC) sao consistentes com as motivacoes mapeadas (Eneagrama, MVPI), garantindo coerencia entre como a pessoa funciona e o que a move.

## Criterios de Aprovacao

### Obrigatorios (todos devem passar)
- [ ] Tipo MBTI comparado com tipo do Eneagrama — Evidencia: `analise de correlacao MBTI x Enea com tabela de frequencia`
- [ ] Funcoes cognitivas dominantes comparadas com core desire do Eneagrama — Evidencia: `analise funcao dominante vs motivacao central`
- [ ] Estilo DISC comparado com drivers motivacionais — Evidencia: `mapeamento DISC x 12 Driving Forces`
- [ ] Correlacoes tipicas (ex: INTJ com Enea 5) verificadas — Evidencia: `comparacao com correlacoes estatisticas conhecidas`
- [ ] Correlacoes atipicas sinalizadas e investigadas — Evidencia: `lista de combinacoes atipicas com investigacao`
- [ ] Asa e instinto do Eneagrama comparados com funcoes auxiliares MBTI — Evidencia: `analise cruzada asa/instinto x funcoes auxiliares`
- [ ] Valores MVPI alinhados com motivacao do tipo — Evidencia: `comparacao MVPI x expectativa motivacional do tipo`
- [ ] Incoerencias entre tipo e motivacao classificadas por severidade — Evidencia: `lista de incoerencias com severidade`

### Desejaveis (aumentam confianca)
- [ ] Nivel de integracao/desintegracao do Eneagrama foi comparado com funcao inferior MBTI
- [ ] Subtipo do Eneagrama foi considerado na analise
- [ ] Respondente confirmou coerencia percebida entre tipo e motivacao
- [ ] Literatura sobre correlacoes MBTI-Eneagrama foi consultada

## Evidencia Necessaria
- Tabela MBTI x Eneagrama com analise
- Mapeamento DISC x Driving Forces
- Verificacao contra correlacoes estatisticas
- Lista de combinacoes atipicas investigadas
- Comparacao MVPI x expectativa motivacional
- Lista de incoerencias com severidade

## Acao se Falhar
- Se comparacao MBTI-Enea nao foi feita: construir analise cruzada sistematica
- Se combinacao atipica nao foi investigada: verificar se tipo ou motivacao foi mal identificado
- Se incoerencias nao foram classificadas: aplicar criterios de severidade padrao
- Se valores MVPI divergem do tipo: investigar se valores sao autenticos ou adaptativos

## Agente Responsavel
- **Agente principal**: Agente de Cross-Framework
- **Agentes de suporte**: Agente de Tipos, Agente de Motivacao
- **Aprovador final**: Agente de Qualidade
