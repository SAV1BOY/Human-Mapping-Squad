# Checklist: Consistencia Motivacoes para Forcas

## Proposito
Verificar que as motivacoes identificadas (Eneagrama, MVPI) sao consistentes com as forcas mapeadas (CliftonStrengths, VIA), garantindo que o que move a pessoa se reflete no que ela faz bem.

## Criterios de Aprovacao

### Obrigatorios (todos devem passar)
- [ ] Core desire do Eneagrama comparado com dominio dominante do CliftonStrengths — Evidencia: `analise core desire vs dominio (Executing, Influencing, Relationship, Strategic)`
- [ ] Tipo do Eneagrama comparado com signature strengths VIA — Evidencia: `tabela tipo Enea x forcas VIA esperadas vs encontradas`
- [ ] Drivers motivacionais (12DF) comparados com forcas top 5 Clifton — Evidencia: `matriz drivers x forcas com alinhamento`
- [ ] Forcas que servem ao core desire foram identificadas — Evidencia: `lista de forcas instrumentais ao core desire`
- [ ] Forcas que conflitam com motivacao principal foram sinalizadas — Evidencia: `lista de conflitos forca-motivacao`
- [ ] Padroes de uso de forcas refletem prioridades motivacionais — Evidencia: `analise de frequencia de uso vs hierarquia motivacional`
- [ ] Motivacoes sem forcas correspondentes foram sinalizadas — Evidencia: `gaps motivacao-forca identificados`
- [ ] Forcas sem motivacao correspondente foram investigadas — Evidencia: `forcas orfas analisadas (habilidade sem desejo?)`

### Desejaveis (aumentam confianca)
- [ ] Instinto do Eneagrama foi correlacionado com dominio CliftonStrengths
- [ ] Momentos de flow foram usados para validar alinhamento motivacao-forca
- [ ] Satisfacao no uso de forcas foi correlacionada com motivacao
- [ ] Forcas latentes foram correlacionadas com motivacoes reprimidas

## Evidencia Necessaria
- Analise core desire vs dominio CliftonStrengths
- Tabela tipo Enea x forcas VIA
- Matriz drivers x forcas Clifton
- Lista de forcas instrumentais e conflitantes
- Gaps motivacao-forca e forcas orfas

## Acao se Falhar
- Se comparacao nao foi feita: construir analise cruzada sistematica
- Se gaps foram encontrados: investigar se motivacao e recente ou se forca nao foi desenvolvida
- Se conflitos nao foram sinalizados: revisar alinhamento forca a forca com motivacao
- Se forcas orfas existem: investigar se sao habilidades adquiridas sem base motivacional

## Agente Responsavel
- **Agente principal**: Agente de Cross-Framework
- **Agentes de suporte**: Agente de Motivacao, Agente de Forcas
- **Aprovador final**: Agente de Qualidade
