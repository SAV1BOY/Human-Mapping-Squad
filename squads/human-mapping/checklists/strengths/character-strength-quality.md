# Checklist: Qualidade das Forcas de Carater

## Proposito
Verificar que as forcas de carater (VIA Classification) foram identificadas corretamente, com signature strengths claras e diferenciadas de forcas situacionais.

## Criterios de Aprovacao

### Obrigatorios (todos devem passar)
- [ ] Perfil VIA completo com ranking das 24 forcas — Evidencia: `resultado VIA com scores por forca`
- [ ] Signature strengths (top 5) identificadas com clareza — Evidencia: `lista de signature strengths com justificativa`
- [ ] Cada signature strength validada com os 5 criterios VIA — Evidencia: `checklist dos 5 criterios por signature strength`
- [ ] Forcas de carater diferenciadas de forcas de performance (CliftonStrengths) — Evidencia: `tabela comparativa VIA vs Clifton`
- [ ] Virtudes associadas foram mapeadas (sabedoria, coragem, etc.) — Evidencia: `agrupamento por virtude com forcas correspondentes`
- [ ] Subuso de forcas de carater foi investigado — Evidencia: `analise de forcas no bottom 5 com impacto`
- [ ] Uso excessivo de forcas de carater foi sinalizado — Evidencia: `exemplos de overuse com consequencias`
- [ ] Contextos onde signature strengths se manifestam foram documentados — Evidencia: `mapeamento forca x contexto de ativacao`

### Desejaveis (aumentam confianca)
- [ ] Respondente realizou exercicio de identificacao de momentos de orgulho
- [ ] Forcas de carater foram correlacionadas com satisfacao de vida
- [ ] Combinacoes unicas de signature strengths foram analisadas
- [ ] Forcas de carater foram comparadas com percepcao de terceiros

## Evidencia Necessaria
- Perfil VIA completo com scores
- Validacao das signature strengths com criterios VIA
- Tabela comparativa VIA vs CliftonStrengths
- Analise de subuso e overuse
- Mapeamento de contextos de ativacao

## Acao se Falhar
- Se perfil VIA esta incompleto: solicitar realizacao completa do assessment
- Se signature strengths nao passam nos 5 criterios: revisar classificacao e considerar proximas do ranking
- Se nao ha diferenciacao com CliftonStrengths: criar tabela comparativa explicita
- Se subuso nao foi investigado: analisar bottom 5 e seu impacto no bem-estar

## Agente Responsavel
- **Agente principal**: Agente de Forcas
- **Agentes de suporte**: Agente de Motivacao, Agente de Sintese
- **Aprovador final**: Agente de Qualidade
