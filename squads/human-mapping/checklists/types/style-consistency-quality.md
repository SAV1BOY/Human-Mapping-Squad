# Checklist: Qualidade da Consistência entre Estilos

## Propósito
Garantir que os estilos inferidos por diferentes modelos (MBTI, DISC, Insights, Social Style) são consistentes entre si.

## Critérios
- [ ] Mapeamento MBTI para DISC foi realizado e verificado — Evidência: `tabela de correspondência MBTI-DISC preenchida`
- [ ] Mapeamento MBTI para Insights Discovery foi realizado — Evidência: `correspondência MBTI-Insights verificada`
- [ ] Mapeamento DISC para Social Styles foi realizado — Evidência: `correspondência DISC-Social Styles verificada`
- [ ] Inconsistências entre modelos foram identificadas — Evidência: `lista de inconsistências cross-modelo gerada`
- [ ] Cada inconsistência foi analisada quanto à causa provável — Evidência: `análise causal por inconsistência`
- [ ] Inconsistências legítimas (modelos medem construtos diferentes) foram diferenciadas de erros — Evidência: `classificação de inconsistências`
- [ ] Respondente foi consultado sobre inconsistências relevantes — Evidência: `clarificações solicitadas e recebidas`
- [ ] Score de consistência cross-modelo foi calculado — Evidência: `campo score_consistencia_modelos preenchido`
- [ ] Narrativa integradora dos múltiplos modelos foi construída — Evidência: `campo narrativa_integradora preenchido`
- [ ] Modelo mais confiável para este respondente foi identificado — Evidência: `campo modelo_mais_confiavel definido`
- [ ] Perfil integrado foi gerado sem contradições não explicadas — Evidência: `perfil integrado validado`
- [ ] Relatório apresenta os modelos como complementares, não redundantes — Evidência: `seção complementaridade no relatório`

## Ação se Falhar
Investigar a fonte da inconsistência (mudança de contexto, fadiga, ambiguidade). Se a inconsistência for irreconciliável, apresentar ambos os resultados com nota explicativa. Priorizar o modelo com maior confiança e evidência para as conclusões principais.
