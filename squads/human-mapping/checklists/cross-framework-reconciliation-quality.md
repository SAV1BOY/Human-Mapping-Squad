# Checklist: Qualidade da Reconciliacao Cross-Framework

## Proposito
Garantir que conflitos e divergencias entre diferentes frameworks psicologicos utilizados no mapeamento foram identificados, analisados e resolvidos com justificativa documentada.

## Criterios de Aprovacao

### Obrigatorios (todos devem passar)
- [ ] Todos os frameworks utilizados na sessao foram listados — Evidencia: `lista completa de frameworks`
- [ ] Comparacao sistematica entre frameworks foi realizada — Evidencia: `matriz de comparacao preenchida`
- [ ] Convergencias entre frameworks foram documentadas — Evidencia: `lista de pontos de convergencia`
- [ ] Divergencias entre frameworks foram identificadas — Evidencia: `lista de divergencias com descricao`
- [ ] Cada divergencia foi classificada por severidade — Evidencia: `classificacao de severidade por divergencia`
- [ ] Divergencias significativas foram analisadas em profundidade — Evidencia: `analise detalhada por divergencia severa`
- [ ] Resolucao ou reconciliacao foi proposta para cada divergencia — Evidencia: `proposta de resolucao documentada`
- [ ] Justificativa da resolucao esta documentada — Evidencia: `justificativa por resolucao`
- [ ] Resultado da reconciliacao foi incorporado na sintese — Evidencia: `sintese reflete reconciliacoes`
- [ ] Confianca na reconciliacao foi quantificada — Evidencia: `score de confianca por reconciliacao`

### Desejaveis (aumentam confianca)
- [ ] Limitacoes conhecidas de cada framework foram consideradas na analise
- [ ] Dominios de validade de cada framework foram respeitados
- [ ] Meta-analise de porque os frameworks divergem foi realizada
- [ ] Hierarquia de precedencia entre frameworks foi documentada quando necessario
- [ ] Respondente foi consultado em divergencias criticas

## Evidencia Necessaria
- Lista de todos os frameworks utilizados na sessao
- Matriz de comparacao entre frameworks
- Lista de convergencias identificadas
- Lista de divergencias com classificacao de severidade
- Analise detalhada de divergencias significativas
- Proposta de resolucao com justificativa por divergencia
- Registro de incorporacao na sintese
- Score de confianca por reconciliacao

## Acao se Falhar
- Se frameworks nao foram listados: compilar lista completa de frameworks utilizados
- Se comparacao nao foi feita: executar comparacao sistematica
- Se divergencias nao foram identificadas: revisar resultados buscando conflitos
- Se divergencias nao foram classificadas: aplicar criterio de severidade
- Se resolucao nao foi proposta: analisar e propor reconciliacao para cada divergencia
- Se justificativa esta ausente: documentar razoes da resolucao escolhida
- Se reconciliacoes nao estao na sintese: incorporar antes de finalizar
- Divergencias criticas sem resolucao devem bloquear a finalizacao do relatorio

## Agente Responsavel
- **Agente principal**: Agente de Cross-Framework
- **Agentes de suporte**: Todos os agentes de camada que utilizam frameworks
- **Aprovador final**: Agente de Qualidade
