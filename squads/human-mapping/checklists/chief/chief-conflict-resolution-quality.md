# Checklist: Qualidade da Resolucao de Conflitos pelo Chief

## Proposito
Garantir que o Chief resolveu todos os conflitos entre frameworks com justificativa documentada e sem contradições em aberto.

## Criterios Obrigatorios
- [ ] Todos os conflitos entre frameworks foram identificados e listados — Evidencia: `___`
- [ ] Cada conflito possui uma resolucao documentada com justificativa clara — Evidencia: `___`
- [ ] Nao existem contradições em aberto sem explicacao — Evidencia: `___`
- [ ] A resolucao considera a hierarquia de confiança entre frameworks — Evidencia: `___`
- [ ] Chief consultou os agentes especialistas relevantes antes de decidir — Evidencia: `___`
- [ ] A decisao de resolucao foi comunicada a todos os agentes impactados — Evidencia: `___`
- [ ] Contradições residuais foram explicitamente marcadas como tensoes validas e justificadas — Evidencia: `___`
- [ ] Chief documentou o criterio de desempate utilizado em cada conflito — Evidencia: `___`
- [ ] Resolucoes nao distorceram os dados originais dos frameworks — Evidencia: `___`

## Criterios Desejaveis
- [ ] Chief categorizou os conflitos por severidade (alto, medio, baixo impacto)
- [ ] Chief identificou padroes recorrentes entre os conflitos encontrados
- [ ] Resolucoes incluem referencia cruzada com evidencias comportamentais
- [ ] Chief sugeriu ajustes no processo para evitar conflitos similares no futuro

## Acao se Falhar
Reabrir a analise de conflitos, convocar os agentes especialistas para revisao conjunta, documentar cada contradição com justificativa explicita e re-submeter para aprovacao.

human-mapping-chief
