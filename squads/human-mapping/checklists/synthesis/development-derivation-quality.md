# Checklist: Qualidade da Derivacao de Areas de Desenvolvimento

## Proposito
Garantir que areas de desenvolvimento foram derivadas de evidencia do perfil, com cada recomendacao apontando para a evidencia que a sustenta.

## Criterios Obrigatorios
- [ ] Cada area de desenvolvimento esta derivada de evidencia concreta do perfil — Evidencia: `___`
- [ ] Cada recomendacao aponta explicitamente para a evidencia que a sustenta — Evidencia: `___`
- [ ] Nenhuma recomendacao foi baseada em suposicoes ou intuicao — Evidencia: `___`
- [ ] Areas de desenvolvimento sao coerentes com o perfil integrado — Evidencia: `___`
- [ ] Recomendacoes sao acionaveis e especificas, nao vagas — Evidencia: `___`
- [ ] Prioridade das areas de desenvolvimento foi definida com criterio explicito — Evidencia: `___`
- [ ] Desenvolvimento proposto respeita as forcas naturais da pessoa — Evidencia: `___`
- [ ] Riscos de desenvolvimento forcado contra o perfil foram sinalizados — Evidencia: `___`
- [ ] Rastreabilidade completa: de evidencia a area a recomendacao — Evidencia: `___`

## Criterios Desejaveis
- [ ] Timeline sugerida para cada area de desenvolvimento foi incluida
- [ ] Recursos e estrategias especificas de desenvolvimento foram sugeridos
- [ ] Quick wins versus desenvolvimentos de longo prazo foram diferenciados
- [ ] Impacto esperado de cada desenvolvimento na performance foi estimado
- [ ] Metricas de acompanhamento do desenvolvimento foram propostas
- [ ] Desenvolvimento foi alinhado com objetivos de carreira quando disponiveis

## Acao se Falhar
Retornar ao development-planner para revisao da derivacao. Exigir que cada recomendacao tenha link explicito com evidencia do perfil. Remover recomendacoes sem fundamentacao e re-submeter.
