# Checklist: Qualidade da Prevencao do Efeito Barnum

## Proposito
Garantir que o perfil e especifico para esta pessoa e nao generico, passando no teste "Outra pessoa rejeitaria esta descricao?".

## Criterios Obrigatorios
- [ ] Cada descricao do perfil e especifica o suficiente para diferenciar esta pessoa de outras — Evidencia: `___`
- [ ] Teste Barnum aplicado: "Outra pessoa rejeitaria esta descricao?" — Resultado positivo — Evidencia: `___`
- [ ] Descricoes genericas tipo horoscopo foram eliminadas ou substituidas — Evidencia: `___`
- [ ] Afirmacoes vagas como "voce e criativo mas tambem analitico" foram especificadas — Evidencia: `___`
- [ ] Cada traco descrito inclui intensidade, contexto ou manifestacao especifica — Evidencia: `___`
- [ ] Perfil nao utiliza linguagem que se aplicaria a maioria das pessoas — Evidencia: `___`
- [ ] Descricoes incluem diferenciais unicos desta pessoa — Evidencia: `___`
- [ ] Combinacao unica de tracos, motivacoes e padroes foi destacada — Evidencia: `___`
- [ ] Revisao anti-Barnum foi formalmente executada e documentada — Evidencia: `___`

## Criterios Desejaveis
- [ ] Exemplos comportamentais especificos foram incluidos para cada descricao
- [ ] Perfil identifica o que esta pessoa NAO e (diferenciais negativos)
- [ ] Descricoes foram comparadas com perfis genericos para validar especificidade
- [ ] Feedback do respondente sobre a precisao das descricoes foi coletado
- [ ] Percentual de descricoes que passaram no teste Barnum foi documentado

## Acao se Falhar
Retornar ao respondent-quality-auditor para revisao rigorosa anti-Barnum. Substituir todas as descricoes genericas por descricoes especificas com evidencia. Re-submeter somente apos 100% das descricoes passarem no teste de especificidade.

## Agente Responsavel
respondent-quality-auditor
