# Checklist: Qualidade da Profundidade Motivacional

## Proposito
Verificar que a motivacao profunda foi separada da superficial, com core fear e core desire claramente identificados e diferenciados de desejos circunstanciais.

## Criterios de Aprovacao

### Obrigatorios (todos devem passar)
- [ ] Motivacao profunda (core) separada de motivacao superficial (circunstancial) — Evidencia: `classificacao de cada motivacao como core ou superficial`
- [ ] Core fear identificado com evidencia comportamental — Evidencia: `descricao do core fear + 3 exemplos de comportamento de evitacao`
- [ ] Core desire identificado com evidencia comportamental — Evidencia: `descricao do core desire + 3 exemplos de comportamento de busca`
- [ ] Relacao core fear/desire com tipo do Eneagrama verificada — Evidencia: `mapeamento fear/desire vs tipo enea`
- [ ] Motivacoes superficiais rastreadas ate sua raiz profunda — Evidencia: `arvore de motivacao mostrando cadeia causal`
- [ ] Teste de profundidade aplicado (pergunta "por que" ate o nivel fundamental) — Evidencia: `registro do exercicio de aprofundamento`
- [ ] Motivacao intrinseca separada de extrinseca — Evidencia: `classificacao intrinseca vs extrinseca por item`
- [ ] Padroes de auto-sabotagem ligados ao core fear documentados — Evidencia: `lista de padroes com frequencia estimada`

### Desejaveis (aumentam confianca)
- [ ] Respondente validou o core fear e core desire identificados
- [ ] Linha do tempo de evolucao motivacional foi construida
- [ ] Gatilhos emocionais ligados ao core fear foram mapeados
- [ ] Mecanismos de compensacao foram identificados

## Evidencia Necessaria
- Classificacao completa de motivacoes (core vs superficial)
- Descricao do core fear com exemplos comportamentais
- Descricao do core desire com exemplos comportamentais
- Arvore de motivacao com cadeia causal
- Mapeamento com tipo do Eneagrama
- Registro do exercicio de aprofundamento

## Acao se Falhar
- Se core fear nao foi identificado: aplicar exercicio de aprofundamento com tecnica dos 5 porques
- Se motivacao profunda e superficial estao misturadas: refazer classificacao com criterios mais rigorosos
- Se nao ha evidencia comportamental: coletar exemplos concretos de situacoes passadas
- Se relacao com Eneagrama nao confere: investigar possibilidade de tipo incorreto ou variacao de asa

## Agente Responsavel
- **Agente principal**: Agente de Motivacao
- **Agentes de suporte**: Agente de Contradicao, Agente de Calibracao
- **Aprovador final**: Agente de Qualidade
