# Workplace Behavior Map

## Propósito

O Workplace Behavior Map traduz dados de traços, tipos e motivações em comportamentos observáveis no ambiente de trabalho. Frameworks de assessment falam em "Conscientiousness", "ENTJ", "Achiever" — mas o que isso significa na prática do dia a dia? Como a pessoa se comunica em reuniões? Como lida com conflito? Como toma decisões? Como lidera?

Este mapa faz a ponte entre construto psicológico e comportamento organizacional. Para cada categoria de comportamento no trabalho, define quais frameworks são mais preditivos e como traduzir scores em expectativas comportamentais concretas.

## Quando Usar

- Na redação de qualquer relatório que será usado em contexto profissional
- Para alimentar o Executive Brief com linguagem de comportamento no trabalho
- Em sessões de devolutiva para gestores ("como isso aparece no dia a dia")
- Na preparação de planos de onboarding baseados em perfil
- Em mapeamento de equipe para entender dinâmicas de trabalho
- Quando o solicitante pergunta "mas na prática, como essa pessoa funciona?"

## Modelo / Estrutura

### As 8 Categorias de Comportamento no Trabalho

#### Categoria 1: Comunicação
**Frameworks mais preditivos**: DISC (primário), Big Five E e A, MBTI E/I e T/F

| Perfil | Comportamento Esperado |
|--------|----------------------|
| DISC D alto / Big Five E alto, A baixo | Comunicação direta, objetiva, pode parecer brusca. Vai ao ponto. Prefere brevidade. |
| DISC I alto / Big Five E alto, A alto | Comunicação expressiva, storytelling, entusiasta. Pode divagar. Engaja emocionalmente. |
| DISC S alto / Big Five A alto, E moderado | Comunicação diplomática, ouve antes de falar, evita confronto verbal. Pode omitir opinião. |
| DISC C alto / Big Five C alto, O moderado | Comunicação precisa, factual, detalhada. Pode parecer fria ou excessivamente técnica. |

#### Categoria 2: Tomada de Decisão
**Frameworks mais preditivos**: Kolbe (primário), Big Five O e C, MBTI J/P e T/F, Hogan HPI Prudence

| Perfil | Comportamento Esperado |
|--------|----------------------|
| Kolbe QS alto / Big Five O alto | Decide rápido, aceita risco, confia na intuição. Pode decidir sem dados suficientes. |
| Kolbe FF alto / Big Five C alto | Decide após análise detalhada. Busca dados, compara opções. Pode demorar demais. |
| MBTI T / Big Five A baixo | Decide com lógica, prioriza eficiência sobre harmonia. Pode ignorar impacto humano. |
| MBTI F / Big Five A alto | Decide considerando impacto nas pessoas. Pode evitar decisões impopulares. |

#### Categoria 3: Gestão de Conflito
**Frameworks mais preditivos**: Hogan HDS (primário), Big Five A e N, DISC, Eneagrama

| Perfil | Comportamento Esperado |
|--------|----------------------|
| Big Five A baixo, N baixo / Hogan HDS Bold | Enfrenta conflito diretamente, pode escalar. Não evita confronto. |
| Big Five A alto, N alto / DISC S | Evita conflito, internaliza tensão, pode acumular resentimento. |
| Eneagrama Tipo 8 / DISC D | Vê conflito como natural. Pode provocar conflito para "limpar o ar". |
| Eneagrama Tipo 9 / Big Five A alto | Minimiza conflito, busca harmonia, pode negar que há problema. |

#### Categoria 4: Liderança
**Frameworks mais preditivos**: Hogan HPI + HDS (primários), Big Five, CliftonStrengths domains, Birkman

| Perfil | Estilo de Liderança Esperado |
|--------|----------------------------|
| Hogan Ambition alto, Sociability alto | Líder carismático, visível, energiza o time. Risco: depende de holofote. |
| Hogan Ambition alto, Sociability baixo | Líder estratégico, opera nos bastidores. Risco: parece distante. |
| CliftonStrengths dominante em Executing | Líder por exemplo, "faz junto". Risco: microgerenciamento. |
| CliftonStrengths dominante em Strategic | Líder visionário, define direção. Risco: desconexão com execução. |
| Hogan HDS Cautious elevado | Sob stress: paralisa, evita risco, não decide. |
| Hogan HDS Bold elevado | Sob stress: centraliza, ignora feedback, age sozinho. |

#### Categoria 5: Colaboração
**Frameworks mais preditivos**: Belbin (primário), DISC, Big Five A e E, CliftonStrengths Relationship

| Perfil | Comportamento Esperado |
|--------|----------------------|
| Belbin Teamworker / Big Five A alto | Colaborativo, flexível, constrói pontes. Pode evitar expressar discordância. |
| Belbin Shaper / DISC D alto | Dirige o grupo, pressiona por resultado. Pode atropelar processos do time. |
| Belbin Plant / Big Five O alto | Contribui com ideias originais mas pode se desengajar de tarefas rotineiras. |
| CliftonStrengths Relator / Big Five E moderado | Colabora profundamente com poucos. Pode resistir a trabalhar com desconhecidos. |

#### Categoria 6: Inovação
**Frameworks mais preditivos**: Big Five O (primário), Kolbe QS, CliftonStrengths Ideation/Strategic, MBTI N

| Perfil | Comportamento Esperado |
|--------|----------------------|
| Big Five O alto, Kolbe QS alto | Gera ideias abundantemente e age rápido para testar. Risco: muitos projetos inacabados. |
| Big Five O alto, Kolbe QS baixo | Gera ideias mas precisa de processo estruturado para implementar. Inovação lenta mas sólida. |
| Big Five O baixo, Kolbe FT alto | Não é fonte de inovação radical mas excelente em implementar e refinar inovações dos outros. |
| MBTI N forte, CliftonStrengths Futuristic | Pensa em possibilidades futuras. Pode frustrar-se com foco no presente. |

#### Categoria 7: Execução
**Frameworks mais preditivos**: Kolbe (primário), Big Five C, Hogan HPI Prudence, CliftonStrengths Executing

| Perfil | Comportamento Esperado |
|--------|----------------------|
| Big Five C alto, Kolbe FT alto | Execução consistente, sistemática, confiável. Entrega no prazo. Pode ser inflexível. |
| Big Five C moderado, Kolbe QS alto | Execução em rajadas. Alta energia no início, pode perder momentum. |
| CliftonStrengths Achiever + Discipline | Produtividade alta e constante. Precisa de lista de tarefas. Fica inquieto sem produzir. |
| Kolbe QS baixo, FF alto, FT alto | Execução lenta mas meticulosa. Pesquisa antes, planeja, e entrega com qualidade. |

#### Categoria 8: Comportamento sob Stress
**Frameworks mais preditivos**: Hogan HDS (primário), Birkman stress, Big Five N, Eneagrama (direção de stress)

| Perfil | Comportamento Esperado |
|--------|----------------------|
| Hogan HDS Excitable alto | Sob stress: volatilidade emocional, mudanças de humor, entusiasmo seguido de desânimo. |
| Hogan HDS Skeptical alto | Sob stress: desconfiança, cinismo, atribui más intenções aos outros. |
| Hogan HDS Reserved alto | Sob stress: isolamento, comunicação mínima, parece "desligar". |
| Hogan HDS Leisurely alto | Sob stress: resistência passiva, coopera superficialmente mas sabota por omissão. |
| Big Five N alto | Sob stress: ansiedade visível, dificuldade de concentração, ruminação. |
| Birkman stress ativado | Comportamento regressivo: necessidades não atendidas → comportamento oposto ao usual. |

## Como Aplicar (step by step)

### Step 1: Identificar Categorias Relevantes
- Consultar o objetivo do assessment (Intake Canvas Q1)
- Se contratação: focar em execução, comunicação, liderança, stress
- Se desenvolvimento: focar em todas as categorias
- Se equipe: focar em comunicação, colaboração, conflito

### Step 2: Para Cada Categoria, Consultar Frameworks Preditivos
- Verificar quais frameworks preditivos foram aplicados
- Coletar os resultados relevantes

### Step 3: Mapear Perfil para Comportamento
- Usar as tabelas acima como referência
- Cruzar múltiplos frameworks para refinar a predição
- Exemplo: DISC D alto + Big Five A baixo + Hogan HDS Bold = comunicação muito direta, liderança assertiva, risco de arrogância sob stress

### Step 4: Redigir em Linguagem de Comportamento
- Traduzir scores em frases comportamentais observáveis
- "Em reuniões, tende a ir direto ao ponto e pode cortar explicações longas"
- NÃO: "Score D alto no DISC indica dominância"

### Step 5: Validar com Dados Observacionais
- Se disponíveis, comparar predição com feedback 360, referências, etc.
- Ajustar quando a predição não bate com a realidade observada

### Step 6: Integrar na Síntese e Brief
- Alimentar o Persona Synthesis com linguagem comportamental
- Alimentar o Executive Brief (especialmente "Como Age")

## Critérios de Qualidade

| Critério | Indicador |
|----------|-----------|
| Comportamental | Descrições são de comportamento observável, não de construtos abstratos |
| Preditivo | Usa frameworks com maior validade preditiva para cada categoria |
| Contextualizado | Considera contexto de trabalho específico da pessoa |
| Balanceado | Inclui comportamento positivo E risco para cada categoria |
| Acionável | O gestor sabe o que esperar e como gerenciar |

## Integração com Pipeline

### Input
- Resultados de todos os frameworks aplicados
- **Adaptation vs Identity Model** → comportamento usual vs sob stress
- **Trait vs Type Model** → interpretação correta dos construtos

### Output
- Linguagem comportamental → **Executive Brief Model** e **Persona Synthesis Model**
- Predições de trabalho → gestores e solicitantes
- Base para → **Development Prioritization** (quais comportamentos desenvolver)

### Posição no Pipeline
```
[Resultados dos Frameworks] → [Workplace Behavior Map] → [Persona Synthesis]
                                        ↓                        ↓
                              [Executive Brief]        [Development Plan]
```

## Exemplos

### Exemplo: Mapa Comportamental Resumido

**Pessoa**: Carlos, Diretor de Operações

| Categoria | Comportamento Esperado | Risco |
|-----------|----------------------|-------|
| Comunicação | Direto, conciso, orientado a resultado | Pode parecer impaciente com detalhes |
| Decisão | Rápida, baseada em experiência e dados top-line | Pode decidir antes de ouvir todas as perspectivas |
| Conflito | Enfrenta abertamente, prefere resolver logo | Pode escalar desnecessariamente |
| Liderança | Estabelece metas claras e cobra resultado | Pode microgerenciar em momentos de crise |
| Colaboração | Colabora com pares, menos com subordinados | Pode criar dinâmica top-down excessiva |
| Inovação | Adota inovação se comprovada, não é early adopter | Pode resistir a mudanças sem ROI claro |
| Execução | Altamente confiável, entrega consistente | Pode priorizar entrega sobre qualidade em crises |
| Stress | Centraliza, aumenta pressão no time, dorme menos | Precisa de mecanismo de descompressão |
