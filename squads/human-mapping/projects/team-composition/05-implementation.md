# Fase 05: Implementação de Mudanças na Composição da Equipe

## Objetivo

Executar as recomendações de composição definidas na Fase 04 (Plano de Ação), gerenciando a transição de forma que respeite os perfis individuais e minimize disrupção na performance da equipe.

## Princípios de Implementação

1. **Transparência:** Mudanças de composição geram ansiedade — comunicar o "porquê" com clareza
2. **Gradualidade:** Mudanças simultâneas demais sobrecarregam a capacidade de adaptação
3. **Respeito ao perfil:** A forma como cada pessoa recebe a mudança depende do seu mapeamento
4. **Reversibilidade:** Sempre que possível, implementar de forma que permita ajustes

## Fases de Implementação

### Fase A: Comunicação (Semana 1-2)

**Ordem de comunicação:**
1. Gestores diretos (antes de qualquer mudança visível)
2. Indivíduos diretamente afetados (1:1, não em grupo)
3. Equipe completa (reunião com contexto e espaço para perguntas)
4. Stakeholders externos (se aplicável)

**Adaptação ao perfil da equipe:**
| Perfil Dominante da Equipe | Formato de Comunicação |
|---------------------------|----------------------|
| Analítico (C alto, Fact Finder alto) | Documento escrito com dados + Q&A |
| Relacional (S alto, Amabilidade alta) | Conversa presencial com espaço emocional |
| Orientado a ação (D alto, Quick Start alto) | Reunião curta + "o que muda na prática" |
| Criativo (Abertura alta, Eneatipo 7) | Visão de futuro + oportunidades |

### Fase B: Transição (Semana 3-6)

#### Novos Papéis ou Responsabilidades
- Definir claramente: o que muda, o que permanece, o que é temporário
- Para cada pessoa realocada, criar mini-onboarding baseado no perfil
- Designar ponto de apoio (buddy) considerando compatibilidade de perfis

#### Novas Dinâmicas de Equipe
- Se há novos pares de trabalho, usar dados de assessment para antecipar:
  - Complementaridades naturais (ex: Fact Finder alto + Quick Start alto)
  - Potenciais atritos (ex: D alto + D alto sem divisão clara de responsabilidade)
  - Necessidades de comunicação diferentes entre pares

#### Acompanhamento Semanal
```
Check-in semanal (15 min por pessoa):
1. Como está se sentindo com a mudança? (1-10)
2. O que está funcionando melhor que o esperado?
3. O que está sendo mais difícil?
4. Do que você precisa que ainda não tem?
```

### Fase C: Estabilização (Semana 7-12)

#### Indicadores de Estabilização
- [ ] Produtividade voltou ao baseline ou superou
- [ ] Conflitos interpessoais estão dentro do esperado
- [ ] Membros realocados se sentem integrados (autorrelato + observação)
- [ ] Gaps identificados na Fase 02 estão sendo preenchidos
- [ ] Novas dinâmicas de equipe estão produzindo os resultados esperados

#### Ajustes Finos
- Microajustes de papel baseados no que emergiu na prática
- Recalibração de expectativas se premissas da Fase 03 se mostraram imprecisas
- Coaching pontual para pares com atrito persistente

## Gestão de Resistência

### Resistência Individual

| Tipo de Resistência | Perfil Típico | Intervenção |
|--------------------|---------------|-------------|
| Medo de perda de status | D alto, Eneatipo 3/8, Ambição alta | Reforçar que mudança não reduz influência; dar visibilidade no novo papel |
| Medo de incompetência | C alto, Eneatipo 1, Conscienciosidade alta | Oferecer treinamento; validar competência existente |
| Medo de mudança | S alto, Eneatipo 6, Neuroticismo alto | Aumentar previsibilidade; comunicar cronograma detalhado; check-ins frequentes |
| Cinismo sobre o processo | Qualquer perfil com experiências negativas anteriores | Ser transparente sobre limitações; demonstrar com ações, não palavras |

### Resistência Coletiva
Se a equipe como um todo demonstra resistência:
1. Pausar implementação (não forçar)
2. Ouvir as preocupações sem defender o plano
3. Identificar se a resistência é ao conteúdo ou ao processo
4. Ajustar abordagem e recomeçar com mais participação da equipe
