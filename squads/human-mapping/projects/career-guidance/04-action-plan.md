# Fase 04 — Plano de Ação de Carreira

## Objetivo
Criar um plano de ação concreto para que o cliente explore e avance nas opções
de carreira identificadas, com etapas claras e prazos definidos.

## Inputs
- Opções de carreira recomendadas (Fase 03)
- Preferências e prioridades do cliente
- Recursos disponíveis (tempo, financeiro, rede de contatos)
- Restrições pessoais e profissionais

## Processo
1. Priorizar opções com o cliente (top 2-3 para exploração)
2. Definir ações de exploração para cada opção:
   - Conversas informativas (informational interviews)
   - Job shadowing ou voluntariado exploratório
   - Cursos ou certificações necessárias
3. Criar cronograma de 90 dias com marcos semanais
4. Identificar recursos e apoios necessários
5. Definir critérios de decisão para escolha final
6. Estabelecer data de revisão e próximos passos

## Outputs
- Plano de ação de 90 dias detalhado
- Top 2-3 opções priorizadas para exploração
- Lista de ações de exploração por opção
- Critérios de decisão para escolha final
- Data de revisão agendada

## Checklist
- [ ] Opções priorizadas com o cliente
- [ ] Ações de exploração definidas
- [ ] Cronograma de 90 dias criado
- [ ] Recursos e apoios identificados
- [ ] Critérios de decisão estabelecidos
- [ ] Data de revisão agendada
- [ ] Plano entregue ao cliente

## Critérios de Decisão

### GO (avançar para próxima fase)
- [ ] Top 2-3 opções priorizadas com o cliente
- [ ] Plano de ação de 90 dias com marcos semanais criado
- [ ] Critérios de decisão para escolha final estabelecidos

### NO-GO (não avançar)
- Cliente não priorizou opções → Ação: sessão de decisão facilitada
- Plano sem ações concretas → Ação: detalhar ações de exploração por opção
