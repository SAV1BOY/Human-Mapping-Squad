# Fase 02 — Forças e Estilo de Trabalho

## Objetivo
Identificar as forças naturais e o estilo de trabalho preferido do cliente para
direcionar a busca de carreiras compatíveis.

## Inputs
- Interesses e valores (Fase 01)
- Resultados CliftonStrengths
- Resultados Kolbe ou DISC (se disponíveis)
- Histórico de realizações profissionais

## Processo
1. Analisar CliftonStrengths e identificar domínios dominantes
2. Mapear estilo de trabalho via Kolbe ou DISC
3. Coletar e analisar histórico de realizações (método STAR)
4. Identificar padrões de excelência recorrentes
5. Cruzar forças com interesses para identificar convergências
6. Mapear ambientes de trabalho ideais (ritmo, estrutura, autonomia)

## Outputs
- Forças Top 5-10 com exemplos contextualizados
- Estilo de trabalho preferido documentado
- Padrões de excelência identificados
- Ambiente de trabalho ideal descrito
- Convergência forças x interesses mapeada

## Checklist
- [ ] CliftonStrengths analisado e contextualizado
- [ ] Estilo de trabalho mapeado
- [ ] Realizações analisadas com método STAR
- [ ] Padrões de excelência documentados
- [ ] Convergência forças x interesses verificada
- [ ] Ambiente ideal descrito

## Critérios de Decisão

### GO (avançar para próxima fase)
- [ ] CliftonStrengths analisado com domínios dominantes identificados
- [ ] Estilo de trabalho mapeado (Kolbe ou DISC)
- [ ] Convergência forças x interesses documentada

### NO-GO (não avançar)
- Nenhum framework de forças avaliado → Ação: aplicar CliftonStrengths ou proxy
- Padrões de excelência não identificados → Ação: conduzir análise de realizações (STAR)
