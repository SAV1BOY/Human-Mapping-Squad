# Fase 03 — Plano de Desenvolvimento

## Objetivo
Criar um plano de desenvolvimento personalizado e acionável para fechar os gaps
prioritários identificados, com ações concretas e cronograma.

## Inputs
- Gaps priorizados (Fase 02)
- Recursos disponíveis (tempo, orçamento, acesso a mentores)
- Preferências de aprendizagem do cliente
- Restrições e compromissos existentes

## Processo
1. Para cada gap prioritário, definir meta SMART
2. Identificar ações de desenvolvimento usando modelo 70-20-10:
   - 70% — experiências práticas no trabalho
   - 20% — aprendizado social (mentoria, coaching, grupos)
   - 10% — aprendizado formal (cursos, leituras, certificações)
3. Criar cronograma realista com marcos mensais
4. Identificar apoios necessários (mentor, coach, gestor)
5. Definir indicadores de progresso para cada meta
6. Estabelecer ritual de acompanhamento (frequência e formato)

## Outputs
- Plano de desenvolvimento individual (PDI) completo
- Metas SMART por gap prioritário
- Cronograma com marcos mensais
- Lista de apoios e recursos necessários
- Indicadores de progresso definidos
- Ritual de acompanhamento estabelecido

## Checklist
- [ ] Metas SMART definidas para cada gap
- [ ] Ações 70-20-10 identificadas
- [ ] Cronograma criado com marcos mensais
- [ ] Apoios e recursos identificados
- [ ] Indicadores de progresso definidos
- [ ] Ritual de acompanhamento acordado
- [ ] PDI registrado no development-plans-registry
