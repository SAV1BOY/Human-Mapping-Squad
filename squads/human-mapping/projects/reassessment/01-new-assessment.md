# Fase 01 — Nova Avaliação

## Objetivo
Aplicar novamente os instrumentos de avaliação utilizados anteriormente para
gerar dados comparáveis e identificar mudanças no perfil.

## Inputs
- Perfil anterior e instrumentos utilizados (Fase 00)
- Instrumentos de avaliação selecionados
- Contexto atual do cliente (cargo, responsabilidades, desafios)

## Processo
1. Aplicar os mesmos instrumentos utilizados na avaliação original
2. Adicionar instrumentos complementares se o escopo expandiu
3. Coletar resultados e verificar validade
4. Documentar contexto atual para qualificar diferenças
5. Registrar quaisquer mudanças no método de aplicação
6. Preparar dados para análise comparativa

## Outputs
- Novos resultados de avaliação completos
- Contexto atual documentado
- Notas sobre mudanças metodológicas (se houver)
- Dados preparados para análise comparativa

## Checklist
- [ ] Mesmos instrumentos reaplicados
- [ ] Instrumentos complementares aplicados (se necessário)
- [ ] Validade dos resultados verificada
- [ ] Contexto atual documentado
- [ ] Mudanças metodológicas registradas
- [ ] Dados preparados para comparação
