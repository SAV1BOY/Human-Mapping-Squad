# Fase 04 — Recomendação Final

## Objetivo
Consolidar todas as análises em uma recomendação clara e fundamentada sobre
a contratação do candidato, com orientações para onboarding se aprovado.

## Inputs
- Análise de fit (Fase 02)
- Análise de riscos (Fase 03)
- Perfil completo do candidato (Fase 01)
- Critérios eliminatórios e desejáveis (Fase 00)

## Processo
1. Consolidar pontos fortes, gaps e riscos em visão integrada
2. Formular recomendação: aprovado, aprovado com ressalvas, ou não recomendado
3. Fundamentar a recomendação com dados objetivos
4. Se aprovado: sugerir estratégias de onboarding alinhadas ao perfil
5. Se aprovado com ressalvas: detalhar condições e monitoramento
6. Redigir relatório final para stakeholders

## Outputs
- Recomendação formal fundamentada
- Relatório de avaliação para decisão do gestor
- Plano de onboarding sugerido (se aprovado)
- Pontos de atenção para os primeiros 90 dias
- Registro no assessment-outcomes registry

## Checklist
- [ ] Visão integrada consolidada
- [ ] Recomendação formulada e fundamentada
- [ ] Relatório redigido para stakeholders
- [ ] Plano de onboarding elaborado (se aplicável)
- [ ] Pontos de atenção para 90 dias documentados
- [ ] Registro no assessment-outcomes atualizado
- [ ] Relatório entregue ao gestor requisitante

## Critérios de Decisão

### GO (avançar para próxima fase)
- [ ] Recomendação formal emitida (aprovado / aprovado com ressalvas / não recomendado)
- [ ] Fundamentação com dados objetivos documentada
- [ ] Relatório entregue ao gestor requisitante

### NO-GO (não avançar)
- Dados conflitantes sem resolução → Ação: análise adicional antes de emitir recomendação
- Stakeholder não disponível para receber relatório → Ação: agendar entrega
