# Fase 08 — Síntese

## Objetivo
Integrar todos os dados coletados e analisados em um perfil coerente e unificado,
criando uma narrativa que captura a essência do cliente de forma precisa e útil.

## Inputs
- Todos os outputs das Fases 02-07
- Análise de contradições resolvida (Fase 07)
- Níveis de confiança consolidados
- Objetivos originais do cliente (Fase 00)

## Processo
1. Revisar todos os dados e análises acumuladas
2. Identificar os temas centrais que emergem do perfil
3. Construir a narrativa integrada do perfil
4. Hierarquizar insights por relevância para os objetivos do cliente
5. Consolidar níveis de confiança finais por dimensão
6. Validar coerência interna da narrativa
7. Preparar sumário executivo e perfil detalhado

## Outputs
- Narrativa integrada do perfil (1-2 páginas)
- Sumário executivo (1 parágrafo)
- Mapa visual do perfil consolidado
- Tabela de confiança por dimensão
- Lista de insights prioritários

## Checklist
- [ ] Todos os dados das fases anteriores revisados
- [ ] Temas centrais identificados e documentados
- [ ] Narrativa integrada escrita e revisada
- [ ] Sumário executivo redigido
- [ ] Níveis de confiança consolidados
- [ ] Coerência interna validada
- [ ] Mapa visual do perfil criado
