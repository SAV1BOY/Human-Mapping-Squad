# Type Taxonomy

## Proposito

Catalogar e organizar todos os personality type systems utilizados pelo Human Mapping Squad,
estabelecendo mapeamentos cruzados entre frameworks para permitir analise integrada e
identificacao de convergencias e contradicoes entre tipologias.

## Categorias

### 1. MBTI (Myers-Briggs Type Indicator) — 16 Tipos

#### Dimensoes
- **E/I**: Extraversion vs Introversion (fonte de energia)
- **S/N**: Sensing vs iNtuition (coleta de informacao)
- **T/F**: Thinking vs Feeling (tomada de decisao)
- **J/P**: Judging vs Perceiving (orientacao ao mundo externo)

#### Os 16 Tipos por Temperamento (Keirsey)
- **NT (Rationals)**: INTJ, INTP, ENTJ, ENTP
- **NF (Idealists)**: INFJ, INFP, ENFJ, ENFP
- **SJ (Guardians)**: ISTJ, ISFJ, ESTJ, ESFJ
- **SP (Artisans)**: ISTP, ISFP, ESTP, ESFP

### 2. DISC — 4 Estilos + Combinacoes

#### Estilos Primarios
- **D (Dominance)**: Direto, orientado a resultados, decisivo, competitivo
- **I (Influence)**: Entusiastico, otimista, colaborativo, expressivo
- **S (Steadiness)**: Paciente, confiavel, colaborativo, estavel
- **C (Conscientiousness)**: Analitico, preciso, sistematico, reservado

#### Combinacoes Frequentes
- **DI / ID**: Lideranca carismatica, ritmo acelerado
- **DC / CD**: Lideranca tecnica, exigente
- **IS / SI**: Relacional e estavel, mediador
- **SC / CS**: Meticuloso e constante, especialista
- **Di, iD, Sc, Cs** (variantes com estilo secundario menor)

### 3. Insights Discovery — 4 Energias Cromáticas

| Cor | Energia | Caracteristicas |
|-----|---------|----------------|
| Fiery Red | Extraverted Thinking | Determinado, competitivo, exigente |
| Sunshine Yellow | Extraverted Feeling | Sociavel, entusiastico, expressivo |
| Earth Green | Introverted Feeling | Calmo, cuidadoso, encorajador |
| Cool Blue | Introverted Thinking | Analitico, preciso, questionador |

### 4. Predictive Index (PI) — 17 Reference Profiles

#### Categorias PI
- **Analytical**: Analyzer, Controller, Specialist, Strategist, Venturer
- **Social**: Altruist, Captain, Collaborator, Maverick, Persuader, Promoter
- **Stabilizing**: Adapter, Craftsman, Guardian, Operator
- **Persistent**: Scholar, Individualist

### 5. PCM (Process Communication Model) — 6 Tipos

| Tipo | Caracteristica Central | Necessidade Psicologica |
|------|----------------------|------------------------|
| Thinker | Logico, organizado | Reconhecimento pelo trabalho, estrutura temporal |
| Persister | Dedicado, observador | Reconhecimento por conviccoes, confianca |
| Harmonizer | Compassivo, sensivel | Reconhecimento como pessoa, necessidades sensoriais |
| Imaginer | Reflexivo, imaginativo | Solidao, tempo proprio |
| Rebel | Espontaneo, criativo | Contato ludico |
| Promoter | Charmoso, adaptavel | Excitacao, acao |

### 6. Birkman Method — 4 Cores

| Cor | Orientacao | Foco |
|-----|-----------|------|
| Red | Doing | Acao pratica, resultados tangiveis |
| Green | Communicating | Relacoes, influencia, persuasao |
| Blue | Thinking | Planejamento, reflexao, inovacao |
| Yellow | Organizing | Processos, estrutura, implementacao |

## Definicoes

| Termo | Definicao Operacional |
|-------|----------------------|
| Type | Categoria discreta que agrupa padroes de personalidade em perfis distintos |
| Type Preference | Tendencia natural dentro de uma dimensao tipologica (nao habilidade) |
| Type Dynamics | Interacao entre funcoes cognitivas dentro de um tipo (especifico ao MBTI) |
| Profile Blend | Combinacao de dois ou mais estilos tipologicos (especifico a DISC, Insights) |
| Stress Pattern | Mudanca de comportamento tipologico sob pressao (especifico ao PCM) |

## Uso no Pipeline

### Na Coleta
- Registrar qual instrumento tipologico foi utilizado e a fonte (self-report, avaliacao formal, observacao)
- Anotar se o tipo foi auto-atribuido ou determinado por assessment validado

### Na Analise
- Utilizar cross-type mapping para verificar convergencia entre frameworks
- Divergencias significativas (ex: DISC D alto + MBTI ISFP) devem ser sinalizadas
- Considerar que tipos sao preferencias, nao caixas rigidas

### Na Sintese
- Nunca reduzir a pessoa a um unico rotulo tipologico
- Apresentar tipo como lente complementar aos traits, nao substitutiva
- Incluir nuances: subtipos, funcoes cognitivas, blends

### Armadilhas Comuns
- Efeito Barnum: descricoes tipologicas genericas que parecem especificas
- Reificacao: tratar tipos como entidades reais em vez de modelos uteis
- Conflacao: assumir que tipos de frameworks diferentes significam a mesma coisa
