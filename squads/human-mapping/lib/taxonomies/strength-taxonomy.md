# Strength Taxonomy

## Proposito

Catalogar e organizar todos os frameworks de strengths utilizados pelo Human Mapping Squad,
diferenciando claramente entre strengths naturais e skills adquiridas, e estabelecendo
mapeamentos entre CliftonStrengths, VIA e Belbin para analise integrada.

## Categorias

### 1. CliftonStrengths (Gallup) — 34 Temas em 4 Dominios

#### 1.1 Executing (como as coisas acontecem)
| Tema | Descricao |
|------|-----------|
| Achiever | Energia constante, produtividade, stamina |
| Arranger | Organizar recursos para maxima eficiencia |
| Belief | Valores centrais estaveis que guiam acao |
| Consistency | Tratar todos igualmente, regras justas |
| Deliberative | Cuidado, precaucao, antecipacao de riscos |
| Discipline | Rotina, estrutura, ordem |
| Focus | Direcao clara, priorizacao, concentracao |
| Responsibility | Compromisso absoluto com o que promete |
| Restorative | Resolver problemas, consertar o que esta quebrado |

#### 1.2 Influencing (como influenciam outros)
| Tema | Descricao |
|------|-----------|
| Activator | Impaciente para agir, catalisa movimento |
| Command | Presenca, controle, decisao sob pressao |
| Communication | Articular ideias, contar historias, dar vida a palavras |
| Competition | Comparacao, consciencia de performance relativa |
| Maximizer | Transformar algo bom em excelente |
| Self-Assurance | Confianca na propria capacidade de julgamento |
| Significance | Desejo de impacto, reconhecimento, importancia |

#### 1.3 Relationship Building (como constroem relacoes)

|------|-----------|

#### 1.4 Strategic Thinking (como analisam e decidem)
| Tema | Descricao |
|------|-----------|
| Analytical | Busca por dados, evidencias, prova logica |
| Context | Entender o passado para informar o presente |

## Strength vs Skill: Distincao Fundamental

| Criterio | Strength (Natural) | Skill (Adquirida) |
|----------|-------------------|-------------------|
| Origem | Talento inato + investimento | Treinamento + pratica |
| Energia | Energiza ao usar | Pode drenar ao usar |
| Aprendizado | Rapido, quase automatico | Requer esforco deliberado |
| Yearning | Sente falta quando nao usa | Nao gera saudade |
| Satisfacao | Intrinseca, "flow" | Extrinseca, competencia |
| Ceiling | Alto potencial de excelencia | Bom, raramente excepcional |
