# Team Composition Rubric

## Proposito

Avaliar a qualidade da composicao de uma equipe usando dados de mapeamento individual dos membros. Uma equipe bem composta nao e um conjunto de pessoas excelentes — e um conjunto de pessoas que se complementam em papeis, perspectivas, motivacoes e estilos de comunicacao.

Esta rubrica define criterios objetivos para avaliar cobertura de papeis, diversidade cognitiva, alinhamento motivacional e compatibilidade de comunicacao.

## Dimensao 1: Cobertura de Papeis (Belbin)

### Criterio
Todas as 9 funcoes Belbin devem estar cobertas por pelo menos um membro da equipe. Funcoes criticas para o tipo de trabalho da equipe devem ter cobertura forte (score alto).

### Avaliacao

| Score | Criterio |
|-------|----------|
| 0.0-0.3 | 3+ funcoes Belbin sem cobertura, incluindo funcoes criticas |
| 0.3-0.5 | 2-3 funcoes sem cobertura, funcoes criticas parcialmente cobertas |
| 0.5-0.7 | 1-2 funcoes sem cobertura, funcoes criticas cobertas |
| 0.7-0.9 | Todas as funcoes cobertas, algumas com redundancia excessiva |
| 0.9-1.0 | Todas as funcoes cobertas com distribuicao equilibrada |

### Funcoes Criticas por Tipo de Equipe
- **Equipe de inovacao**: Plant + Resource Investigator + Shaper (essenciais)
- **Equipe de execucao**: Implementer + Completer Finisher + Coordinator (essenciais)
- **Equipe de estrategia**: Monitor Evaluator + Plant + Coordinator (essenciais)
- **Equipe de atendimento**: Teamworker + Resource Investigator + Implementer (essenciais)

## Dimensao 2: Diversidade Cognitiva (Big Five Openness)

### Criterio
Equipes com range amplo de Abertura a Experiencia tendem a ter melhor desempenho em problemas complexos. Homogeneidade extrema (todos altos ou todos baixos) limita a perspectiva.

### Avaliacao

| Score | Criterio |
|-------|----------|
| 0.0-0.3 | Range de Abertura < 15 percentis — equipe cognitivamente homogenea |
| 0.3-0.5 | Range de 15-30 percentis — alguma diversidade |
| 0.5-0.7 | Range de 30-45 percentis — diversidade moderada |
| 0.7-0.9 | Range de 45-60 percentis — alta diversidade com sobreposicao |
| 0.9-1.0 | Range de 60+ percentis com membros em cada terco da distribuicao |

### Nota
Diversidade cognitiva alta gera melhor resultado MAS tambem mais conflito. A equipe precisa de mecanismos de resolucao de conflito para se beneficiar da diversidade.

## Dimensao 3: Alinhamento Motivacional (SDI/Enneagram)

### Criterio
Os membros da equipe devem compartilhar valores suficientes para colaborar, mas ter motivacoes suficientemente diversas para cobrir diferentes necessidades.

### Avaliacao

| Score | Criterio |
|-------|----------|
| 0.0-0.3 | Motivacoes conflitantes dominantes sem mediacao (ex: todos Red SDI competindo) |
| 0.3-0.5 | Motivacoes parcialmente alinhadas mas com pontos de atrito significativos |
| 0.5-0.7 | Mix razoavel de motivacoes com pontos de convergencia identificados |
| 0.7-0.9 | Diversidade motivacional com valores compartilhados claros |
| 0.9-1.0 | Complementaridade motivacional ideal — cada membro contribui de angulo diferente para objetivo comum |

### Combinacoes Tipicas de Risco
- Todos Enneagram tipo 3 → competicao interna destrutiva
- Todos SDI Blue → decisoes lentas por excesso de consenso
- Mix de SDI Red (direto) + SDI Blue (diplomata) sem mediador → conflito de estilo frequente

## Dimensao 4: Compatibilidade de Comunicacao (DISC/PCM)

### Criterio
Os estilos de comunicacao da equipe devem ser suficientemente compativeis para permitir fluxo de informacao eficiente, ou a equipe deve ter consciencia das diferencas e estrategias de adaptacao.

### Avaliacao

| Score | Criterio |
|-------|----------|
| 0.0-0.3 | Estilos de comunicacao incompativeis sem consciencia das diferencas |
| 0.3-0.5 | Incompatibilidades identificadas mas sem estrategia de adaptacao |
| 0.5-0.7 | Mix de estilos com consciencia parcial e algumas adaptacoes |
| 0.7-0.9 | Diversidade de estilos com estrategias de comunicacao explicitadas |
| 0.9-1.0 | Equipe treinada em estilo de comunicacao com adaptacao fluida |

## Score Geral de Composicao

```
Score = (Cobertura Belbin x 0.30) + (Diversidade Cognitiva x 0.20)
      + (Alinhamento Motivacional x 0.25) + (Compatibilidade Comunicacao x 0.25)
```

### Classificacao

| Score | Classificacao | Recomendacao |
|-------|--------------|--------------|
| 0.0-0.4 | Composicao Fragil | Intervencao urgente: gaps criticos de papel ou conflitos estruturais |
| 0.4-0.6 | Composicao Adequada | Melhorias pontuais: treinamento em comunicacao ou adicao de papel faltante |
| 0.6-0.8 | Composicao Forte | Otimizacao: refinar interacoes e aproveitar complementaridades |
| 0.8-1.0 | Composicao Excelente | Manter e monitorar: proteger a dinamica e documentar aprendizados |
