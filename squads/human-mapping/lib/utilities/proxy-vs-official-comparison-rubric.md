# Rubrica: Proxy vs. Instrumento Oficial — Quando Confiar em Cada Um

## Objetivo

Definir critérios claros para decidir quando uma inferência proxy (baseada em observação, entrevista ou convergência de outros frameworks) é suficiente versus quando insistir na aplicação do instrumento oficial.

## Conceitos Fundamentais

### Inferência Proxy
Estimativa de um resultado de assessment baseada em evidências indiretas: comportamento observado, respostas em outros instrumentos, relatos de terceiros, padrões convergentes.

### Instrumento Oficial
Aplicação padronizada do assessment com normas validadas, scoring oficial e interpretação conforme manual do instrumento.

## Critérios de Decisão

### 1. Limiar de Confiança da Inferência Proxy

| Confiança | Descrição | Exemplo |
|-----------|-----------|---------|
| Alta (≥85%) | 3+ fontes convergem; padrão inequívoco | MBTI inferido como INTJ por entrevista + Big Five + Kolbe + DISC — todos apontam mesma direção |
| Média (60-84%) | 2 fontes convergem com alguma ambiguidade | Eneatipo parece 5 ou 1 — evidências divididas |
| Baixa (<60%) | Evidência limitada ou contraditória | Apenas uma observação comportamental, sem dados de outros frameworks |

### 2. Stakes da Decisão

| Stakes | Descrição | Exigência |
|--------|-----------|-----------|
| Altas | Decisão de contratação sênior, promoção, reestruturação de equipe | Instrumento oficial fortemente recomendado |
| Médias | Plano de desenvolvimento, coaching, autoconhecimento | Proxy aceitável se confiança ≥ média |
| Baixas | Exercício exploratório, workshop de equipe, hipótese inicial | Proxy suficiente mesmo com confiança baixa |

### 3. Convergência de Evidências Proxy

| Nível | Fontes | Decisão |
|-------|--------|---------|
| Forte | 3+ frameworks apontam mesma conclusão | Proxy confiável para stakes médias |
| Moderada | 2 frameworks concordam, sem contradição | Proxy aceitável com ressalvas |
| Fraca | 1 framework ou evidências contraditórias | Instrumento oficial necessário |

### 4. Disponibilidade do Instrumento Oficial

| Situação | Abordagem |
|----------|-----------|
| Disponível e viável | Preferir oficial para stakes altas |
| Disponível mas custo/tempo proibitivo | Proxy aceitável com documentação de limitações |
| Indisponível (descontinuado, não licenciado) | Proxy é a única opção — documentar claramente |
| Respondente recusa aplicação oficial | Respeitar; usar proxy com transparência |

### 5. Restrições de Tempo e Custo

| Cenário | Recomendação |
|---------|-------------|
| Orçamento amplo + tempo disponível | Instrumento oficial sempre que possível |
| Orçamento limitado + urgência | Proxy para frameworks secundários; oficial para o primário |
| Sessão única sem possibilidade de retorno | Maximizar proxy com múltiplas fontes na sessão |

## Matriz de Decisão Integrada

```
SE confiança_proxy ≥ Alta E stakes ≤ Médias:
    → USAR PROXY (documentar base)

SE confiança_proxy ≥ Média E stakes = Baixas:
    → USAR PROXY (documentar base)

SE confiança_proxy ≥ Média E stakes = Médias E convergência ≥ Moderada:
    → USAR PROXY com ressalva explícita

SE stakes = Altas:
    → INSTRUMENTO OFICIAL (independente da confiança proxy)
    → Exceção: oficial indisponível → proxy com convergência forte + declaração de limitação

SE confiança_proxy = Baixa E stakes ≥ Médias:
    → NÃO USAR PROXY — buscar instrumento oficial ou mais evidências

EM QUALQUER CASO:
    → Documentar a decisão e a base
    → Nunca apresentar proxy como resultado oficial
```

## Boas Práticas

1. **Sempre rotular** — proxy deve ser identificado como inferência, nunca como resultado certificado
2. **Registrar evidências** — listar quais fontes sustentam a inferência
3. **Declarar o gap** — informar que instrumento oficial não foi aplicado e por quê
4. **Revisitar** — se proxy foi usado por limitação, agendar aplicação oficial quando viável
5. **Não empilhar proxies** — não usar um proxy como evidência para outro proxy

## Riscos de Confiança Excessiva em Proxies

- **Efeito Barnum**: inferência genérica que parece precisa mas serve para qualquer pessoa
- **Viés de confirmação**: facilitador vê o que espera ver nos dados convergentes
- **Falsa precisão**: apresentar proxy com linguagem de certeza que não se justifica
- **Perda de nuance**: instrumentos oficiais capturam facetas que proxies frequentemente perdem
