# Scorer de Compatibilidade de Equipe

## Proposito

Calcular a compatibilidade entre perfis individuais para informar
decisoes de composicao de equipe. Nao busca homogeneidade —
busca complementaridade produtiva.

## Dimensoes de Compatibilidade

### 1. Complementaridade Cognitiva
Avalia se os estilos de pensamento se complementam.

**Kolbe:**
- Quick Start alto + Follow Thru alto = inovacao com execucao
- Fact Finder alto + Quick Start alto = pesquisa com acao
- Score: medir diversidade nos modos de operacao

**Big Five Abertura:**
- Diversidade em abertura = mais perspectivas
- Homogeneidade alta em abertura = risco de "groupthink criativo"
- Homogeneidade baixa = risco de "groupthink conservador"

### 2. Compatibilidade Relacional
Avalia se os estilos de interacao sao compatíveis.

**DISC:**
- D + S pode gerar tensao (velocidade vs cautela)
- I + C pode gerar frustracao (sociabilidade vs foco)
- Complementaridade e desejavel, mas precisa de mediacao

**Big Five Amabilidade:**
- Muito alta para todos = falta de conflito produtivo
- Muito baixa para todos = conflito improdutivo
- Mix ideal: maioria moderada-alta com pelo menos um "desafiador"

### 3. Alinhamento de Valores
Avalia se motivacoes fundamentais sao compatíveis.

**Enneagrama:**
- Tipos do mesmo centro (2,3,4 / 5,6,7 / 8,9,1) compartilham linguagem
- Tipos de centros diferentes trazem diversidade de perspectiva
- Conflitos classicos: 8 vs 9 (poder vs paz), 1 vs 7 (rigor vs liberdade)

## Algoritmo de Score

### Entrada
- Perfis completos de cada membro (Big Five, DISC, Enneagrama, Kolbe)
- Contexto da equipe (tipo de trabalho, fase, desafios)

### Processamento
1. Calcular diversidade cognitiva (0-100)
2. Calcular compatibilidade relacional (0-100)
3. Calcular alinhamento de valores (0-100)
4. Ponderar conforme contexto da equipe

### Saida
- Score geral de compatibilidade (0-100)
- Breakdown por dimensao
- Pontos de sinergia potencial
- Pontos de atrito potencial
- Recomendacoes de gestao

## Interpretacao dos Scores

| Score | Interpretacao |
|-------|--------------|
| 80-100 | Alta compatibilidade natural — monitorar groupthink |
| 60-79 | Boa compatibilidade — tensoes produtivas |
| 40-59 | Compatibilidade moderada — requer gestao ativa |
| 20-39 | Baixa compatibilidade — alto risco de conflito |
| 0-19 | Incompatibilidade severa — reconsiderar composicao |

## Limitacoes

- Compatibilidade nao garante performance
- Contexto e lideranca importam mais que perfis
- Score e indicativo, nao determinístico
- Pessoas crescem e mudam — reavaliar periodicamente
