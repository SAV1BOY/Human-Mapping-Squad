# Personality Types: Using the Enneagram for Self-Discovery

## Autor(es)

Don Richard Riso e Russ Hudson. Riso foi o primeiro autor a sistematizar descricoes detalhadas dos nove tipos do Eneagrama com niveis de desenvolvimento, e Hudson contribuiu com aprofundamento teorico nas edicoes revisadas.

## Ano de Publicacao

1996 (edicao revisada). Primeira edicao de 1987.

## Resumo

Personality Types e a obra de referencia mais detalhada para descricoes dos nove tipos do Eneagrama. Diferentemente de The Wisdom of the Enneagram (que e um guia pratico), este livro foca nas descricoes aprofundadas de cada tipo atraves dos nove niveis de desenvolvimento. Para cada tipo, o livro apresenta o padrao basico de personalidade, motivacoes inconscientes, mecanismos de defesa, comportamentos tipicos em cada nivel de saude psicologica, e direcoes de integracao e desintegracao. E a base teorica mais completa do sistema Riso-Hudson.

## Conceitos Principais

- **Descricoes tipologicas detalhadas:** Cada tipo descrito em profundidade com exemplos comportamentais
- **Nove niveis de desenvolvimento:** Nivel 1 (Liberacao) ate Nivel 9 (Patologia) para cada tipo
- **Estrutura interna dos tipos:** Medo basico, desejo basico, superego message, fixacao cognitiva, paixao emocional
- **Mecanismos de defesa:** Cada tipo utiliza defesas psicologicas especificas
- **Dinamica de asas:** Como os tipos adjacentes modificam a expressao do tipo basico
- **Exemplos biograficos:** Personalidades famosas utilizadas para ilustrar cada tipo
- **Continuum saudavel-nao saudavel:** Personalidade como espectro, nao categoria fixa
- **Potencial de transformacao:** Cada tipo tem um caminho especifico de crescimento

## Relevancia para o Assessment OS

Este livro fornece o vocabulario descritivo mais rico para os nove tipos do Eneagrama. No Assessment OS, as descricoes por nivel de desenvolvimento permitem feedback personalizado e nuancado. O mapeamento de mecanismos de defesa e particularmente util para processos de coaching e desenvolvimento de autoconsciencia em lideres.

## Frameworks Relacionados

- Eneagrama (Wisdom of the Enneagram — guia complementar)
- Psicanalise (mecanismos de defesa associados a cada tipo)
- Teoria do Desenvolvimento do Ego (Loevinger — paralelos com niveis)
- Big Five (traducoes entre tipos e tracos dimensionais)
- Hogan Development Survey (dark side como niveis nao-saudaveis)
