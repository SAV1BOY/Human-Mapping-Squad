# Glossário

## Visão Geral
Glossário de termos técnicos utilizados pelo Human Mapping Squad. Consulte este
documento quando encontrar termos desconhecidos na documentação ou relatórios.

## Conteúdo

| Termo | Definição |
|-------|-----------|
| **Big Five** | Modelo de cinco fatores de personalidade: Abertura, Conscienciosidade, Extroversão, Amabilidade, Neuroticismo |
| **Conação** | Aspecto da mente relacionado ao impulso instintivo de agir, medido pelo Kolbe |
| **Contradição** | Resultado divergente entre dois ou mais frameworks aplicados à mesma pessoa |
| **Descarrilador** | Comportamento de risco que emerge sob estresse e pode prejudicar a eficácia (HDS) |
| **Faceta** | Subdivisão de um domínio ou dimensão de personalidade |
| **Framework** | Sistema teórico e instrumento de avaliação de personalidade |
| **Gold standard** | Instrumento ou método de referência com maior validade reconhecida |
| **Lado brilhante** | Comportamento habitual quando a pessoa está no seu melhor (HPI) |
| **Lado sombrio** | Comportamentos de risco que emergem sob pressão (HDS) |
| **Nível de confiança** | Grau de certeza atribuído a um resultado (0.0 a 1.0) |
| **Persona** | Perfil integrado de um indivíduo mapeado pelo squad |
| **Proxy-inference** | Estimativa de resultado em um framework usando dados de outro |
| **Reassessment** | Reavaliação de um perfil após período de desenvolvimento |
| **RIASEC** | Modelo de interesses vocacionais de Holland (6 tipos) |
| **SMART** | Critério para metas: Específica, Mensurável, Alcançável, Relevante, Temporal |
| **SOTA** | State of the Art — estado da arte em uma área de conhecimento |
| **Teste-reteste** | Medida de consistência de um instrumento ao longo do tempo |
| **Traço** | Dimensão contínua de personalidade (oposto de tipo categórico) |
| **Tipo** | Categoria discreta de personalidade (ex: INTJ no MBTI) |
