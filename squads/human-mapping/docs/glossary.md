# Glossário

## Visão Geral
Glossário de termos técnicos utilizados pelo Human Mapping Squad. Consulte este
documento quando encontrar termos desconhecidos na documentação ou relatórios.

## Conteúdo

| Termo | Definição |
|-------|-----------|
| **Big Five** | Modelo de cinco fatores de personalidade: Abertura, Conscienciosidade, Extroversão, Amabilidade, Neuroticismo |
| **Conação** | Aspecto da mente relacionado ao impulso instintivo de agir, medido pelo Kolbe |
| **Contradição** | Resultado divergente entre dois ou mais frameworks aplicados à mesma pessoa |
| **Descarrilador** | Comportamento de risco que emerge sob estresse e pode prejudicar a eficácia (HDS) |
| **Faceta** | Subdivisão de um domínio ou dimensão de personalidade |
| **Framework** | Sistema teórico e instrumento de avaliação de personalidade |
| **Gold standard** | Instrumento ou método de referência com maior validade reconhecida |
| **Lado brilhante** | Comportamento habitual quando a pessoa está no seu melhor (HPI) |
| **Lado sombrio** | Comportamentos de risco que emergem sob pressão (HDS) |
| **Nível de confiança** | Grau de certeza atribuído a um resultado (0.0 a 1.0) |
| **Persona** | Perfil integrado de um indivíduo mapeado pelo squad |
| **Proxy-inference** | Estimativa de resultado em um framework usando dados de outro |
| **Reassessment** | Reavaliação de um perfil após período de desenvolvimento |
| **RIASEC** | Modelo de interesses vocacionais de Holland (6 tipos) |
| **SMART** | Critério para metas: Específica, Mensurável, Alcançável, Relevante, Temporal |
| **SOTA** | State of the Art — estado da arte em uma área de conhecimento |
| **Teste-reteste** | Medida de consistência de um instrumento ao longo do tempo |
| **Traço** | Dimensão contínua de personalidade (oposto de tipo categórico) |
| **Tipo** | Categoria discreta de personalidade (ex: INTJ no MBTI) |


### Termos Adicionais de Uso Frequente

| Termo | Definição |
|-------|-----------|
| **Assessment** | Processo completo de avaliação de uma persona usando um ou mais frameworks |
| **Calibração** | Etapa de seleção e ajuste de frameworks para um projeto específico |
| **Chief** | Agente líder de uma camada de avaliação (traços, tipos, motivações, forças) |
| **Convergência** | Quando resultados de múltiplos frameworks apontam na mesma direção |
| **Desejabilidade social** | Tendência do respondente de dar respostas socialmente aceitas em vez de honestas |
| **Divergência** | Quando resultados de frameworks diferentes apontam em direções opostas |
| **Efeito Barnum** | Descrição vaga o suficiente para parecer válida para qualquer pessoa |
| **Faceta** | Subdivisão de um domínio (ex: Big Five Extroversão tem 6 facetas) |
| **Gate de qualidade** | Checkpoint obrigatório entre fases do pipeline para validar dados |
| **Handoff** | Transferência estruturada de trabalho entre agentes ou squads |
| **Intake** | Fase inicial de coleta de dados e alinhamento de expectativas |
| **Mapeamento** | Processo completo de construção de um perfil integrado de persona |
| **Normalização** | Ajuste de scores para uma escala comum (percentis, z-scores) |
| **Percentil** | Posição relativa de um score em relação a uma população de referência |
| **Pipeline** | Sequência de etapas do processo de avaliação, do intake ao relatório |
| **Subfaceta** | Nível mais granular de uma dimensão, abaixo da faceta |
| **Threshold** | Valor mínimo de confiança exigido para incluir dado no relatório |
| **Tipologia** | Sistema que classifica pessoas em tipos discretos (ex: MBTI, Eneagrama) |
| **Traço dimensional** | Característica medida em escala contínua, não categórica |
| **Workflow** | Fluxo de trabalho definido que orquestra agentes em sequência |

> **Glossário completo**: para a lista exaustiva de termos com exemplos e
> referências cruzadas, consulte `data/registries/glossary.yaml`.
