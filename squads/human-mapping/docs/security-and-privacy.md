# Seguranca e Privacidade de Dados

## Principios Fundamentais

Dados de assessment sao informacoes sensiveis sobre a psicologia e
comportamento de pessoas. O tratamento inadequado pode causar danos
reais. Este guia estabelece padroes minimos de protecao.

## LGPD — Lei Geral de Protecao de Dados

### Base Legal
- Dados de assessment sao dados pessoais sensiveis (Art. 5, II)
- Requerem consentimento especifico e destacado (Art. 11)
- Finalidade deve ser explicita e limitada
- Titular pode revogar consentimento a qualquer momento

### Consentimento Informado
O consentimento deve incluir:
- Quais dados serao coletados
- Como serao usados (finalidade especifica)
- Quem tera acesso
- Por quanto tempo serao retidos
- Como solicitar exclusao

## Anonimizacao e Pseudonimizacao

### Quando Anonimizar
- Dados agregados para pesquisa ou benchmarking
- Exemplos em treinamentos ou documentacao
- Compartilhamento com terceiros sem necessidade de identificacao

### Como Anonimizar
- Remover nome, email, e identificadores diretos
- Generalizar dados demograficos (faixa etaria, regiao)
- Cuidado com re-identificacao em populacoes pequenas
- K-anonimato: garantir que cada registro se pareca com pelo menos k-1 outros

## Politica de Retencao

| Tipo de Dado | Retencao | Justificativa |
|-------------|----------|---------------|
| Resultados brutos | 2 anos | Reavaliacao e longitudinal |
| Relatorios finais | 5 anos | Historico de desenvolvimento |
| Notas de sessao | 1 ano | Referencia imediata |
| Dados anonimizados | Indefinido | Pesquisa e melhoria |

## Controle de Acesso

- Principio do menor privilegio
- Apenas profissionais diretamente envolvidos acessam dados completos
- Gestores recebem apenas sumario executivo (nao dados brutos)
- Log de acesso para auditoria

## Compartilhamento com Terceiros

- Nunca compartilhar sem consentimento explicito do titular
- Coaches e consultores externos: acordo de confidencialidade
- Plataformas de assessment: verificar compliance com LGPD
- Transferencia internacional: adequacao do pais de destino

## Incidentes de Seguranca

- Notificar ANPD e titulares afetados em caso de vazamento
- Documentar incidente e acoes corretivas
- Revisar controles para prevenir recorrencia
