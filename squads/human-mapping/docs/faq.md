# Perguntas Frequentes (FAQ)

## Visão Geral
Respostas às perguntas mais comuns sobre o Human Mapping Squad, seus serviços,
metodologias e limitações.

## Conteúdo

### Qual a diferença entre traços e tipos?
Traços são dimensões contínuas (você tem mais ou menos de cada um), enquanto
tipos são categorias discretas (você pertence a uma categoria). O squad prefere
traços por serem mais precisos, mas usa tipos como linguagem acessível.

### Qual framework é o mais confiável?
O Big Five (NEO-PI-R) é o gold standard para traços de personalidade. Para
liderança, os Hogan Assessments são referência. Nenhum framework é perfeito
— por isso usamos múltiplos e cruzamos resultados.

### Por que meus resultados em testes diferentes parecem contraditórios?
Contradições são normais e informativas. Podem indicar que você se comporta
diferente em contextos diferentes, que mudou ao longo do tempo, ou que um
dos instrumentos tem limitações. Consulte o `contradiction-resolution-guide.md`.

### Posso usar o perfil para contratação?
Sim, como complemento a um processo seletivo estruturado. Nunca como fator
único de decisão. Consulte o `ethical-use-policy.md` para diretrizes.

### Com que frequência devo refazer minha avaliação?
Recomendamos reavaliação a cada 2-3 anos, ou quando houver mudança
significativa de contexto (novo cargo, nova empresa, transição de carreira).

### O que é proxy-inference e posso confiar nela?
É uma estimativa de resultado baseada em outro framework. É útil quando
avaliação direta não é possível, mas tem confiança reduzida. Sempre
sinalizamos com marcação "[proxy]" no relatório.

### Como solicitar um projeto ao squad?
Consulte o `getting-started.md` para o processo de solicitação e os tipos
de projeto disponíveis.
