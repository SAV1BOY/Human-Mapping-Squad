# Perguntas Frequentes (FAQ)

## Visão Geral
Respostas às perguntas mais comuns sobre o Human Mapping Squad, seus serviços,
metodologias e limitações.

## Conteúdo

### Qual a diferença entre traços e tipos?
Traços são dimensões contínuas (você tem mais ou menos de cada um), enquanto
tipos são categorias discretas (você pertence a uma categoria). O squad prefere
traços por serem mais precisos, mas usa tipos como linguagem acessível.

### Qual framework é o mais confiável?
O Big Five (NEO-PI-R) é o gold standard para traços de personalidade. Para
liderança, os Hogan Assessments são referência. Nenhum framework é perfeito
— por isso usamos múltiplos e cruzamos resultados.

### Por que meus resultados em testes diferentes parecem contraditórios?
Contradições são normais e informativas. Podem indicar que você se comporta
diferente em contextos diferentes, que mudou ao longo do tempo, ou que um
dos instrumentos tem limitações. Consulte o `contradiction-resolution-guide.md`.

### Posso usar o perfil para contratação?
Sim, como complemento a um processo seletivo estruturado. Nunca como fator
único de decisão. Consulte o `ethical-use-policy.md` para diretrizes.

### Com que frequência devo refazer minha avaliação?
Recomendamos reavaliação a cada 2-3 anos, ou quando houver mudança
significativa de contexto (novo cargo, nova empresa, transição de carreira).

### O que é proxy-inference e posso confiar nela?
É uma estimativa de resultado baseada em outro framework. É útil quando
avaliação direta não é possível, mas tem confiança reduzida. Sempre
sinalizamos com marcação "[proxy]" no relatório.

### Como solicitar um projeto ao squad?
Consulte o `getting-started.md` para o processo de solicitação e os tipos
de projeto disponíveis.

### O que fazer se a confiança ficou abaixo de 0.5?
Confiança abaixo de 0.5 indica que o resultado não é confiável para tomada de
decisão. Ações recomendadas: (1) Verificar se o respondente entendeu as perguntas
corretamente. (2) Avaliar se houve fadiga ou pressa nas respostas. (3) Considerar
reaplicar o instrumento específico com mais contexto ou em outro momento.
(4) Se persistir, registrar como "[low-confidence]" no relatório e não usar
esse framework como base para recomendações — apenas como hipótese exploratória.

### Como lidar com respondente que mente deliberadamente?
Primeiro: detectar. Sinais incluem desejabilidade social extrema (scores
"perfeitos demais"), inconsistências entre frameworks, e respostas que não
batem com observação comportamental. Segundo: não confrontar diretamente.
Usar perguntas de profundidade que dificultam manutenção da máscara ("me dá
um exemplo concreto de quando isso aconteceu"). Terceiro: registrar no relatório
com nota de confiança reduzida. Consulte `contradiction-resolution-guide.md`
para o protocolo completo de detecção de desejabilidade social.

### Posso usar só um framework?
Pode, mas a qualidade cai drasticamente. Um único framework captura uma
dimensão da personalidade. O valor do squad está justamente na triangulação
multi-framework. Para contextos com restrição severa de tempo, o mínimo
recomendado é Big Five + 1 framework complementar (ex: DISC para contexto
organizacional, Enneagram para desenvolvimento pessoal). Nunca tome decisão
de contratação baseada em um único instrumento.

### Quanto tempo leva um assessment /deep?
O assessment completo (/deep) com pipeline full leva entre 3 e 5 horas de
interação direta com o respondente, divididas em 2-3 sessões. O processamento
e elaboração do relatório leva mais 2-4 horas. Total do projeto: 5-9 horas.
Para assessments mais rápidos, use /quick (1-2 horas de interação, 1 framework
principal + proxies) ou /standard (2-3 horas, 3 frameworks).

### Como interpretar contradições S3?
Contradições de nível S3 (contradição estrutural entre frameworks) são as mais
informativas. Elas indicam que o respondente opera em registros diferentes
dependendo do contexto, que houve mudança significativa ao longo do tempo, ou
que um dos instrumentos tem limitação para aquele perfil específico. O protocolo
é: (1) Identificar a contradição. (2) Formular hipóteses de resolução.
(3) Investigar com perguntas de profundidade. (4) Registrar no relatório com
a resolução ou como contradição aberta com nota explicativa. Contradições
não resolvidas reduzem o score de confiança global em 3-5%.

### Qual a diferença entre /quick, /standard e /deep?
- **/quick:** 1-2 horas, 1 framework principal + estimativas proxy. Confiança
  global típica: 60-70%. Útil para triagem inicial ou contextos de baixo risco.
- **/standard:** 2-3 horas, 3 frameworks aplicados. Confiança global típica:
  75-85%. Adequado para a maioria dos contextos organizacionais.
- **/deep:** 3-5 horas, pipeline completo (5-6 frameworks + entrevista profunda).
  Confiança global típica: 85-95%. Recomendado para contratações estratégicas,
  desenvolvimento de liderança e mapeamento vocacional profundo.

### O que é o score de confiança global e como é calculado?
É a média ponderada das confianças individuais de cada framework, ajustada por
consistência inter-framework. Frameworks com instrumentos oficiais aplicados
(ex: Gallup para CliftonStrengths) recebem peso maior. Divergências não
resolvidas entre frameworks geram penalidade de 3-5%. Convergências fortes
podem gerar bônus de 1-2%. O score final reflete o quanto podemos confiar na
síntese como um todo, não em cada framework individualmente.

### Como o squad lida com viés cultural nos instrumentos?
Todos os instrumentos têm viés cultural em algum grau. O squad adota três
estratégias: (1) Usar normas brasileiras quando disponíveis (ex: adaptação
brasileira do NEO-PI-R). (2) Quando não há norma local, registrar isso como
fator de redução de confiança. (3) Na entrevista, calibrar perguntas para o
contexto cultural do respondente — o que é "assertividade" no Brasil pode ter
expressão diferente de outros contextos. Consulte `calibracao-cultural.md`.

### O respondente pode ver o relatório completo?
Depende do contrato e do contexto. Em projetos de desenvolvimento pessoal,
sim — o relatório completo é do respondente. Em contextos de seleção, o
respondente recebe uma devolutiva resumida com seus principais achados e
recomendações, mas o relatório com análise de fit e recomendação de contratação
vai apenas para o contratante. Isso deve ser comunicado ao respondente ANTES
da sessão. Consulte `ethical-use-policy.md`.

### O que fazer quando o respondente discorda fortemente do resultado?
Discordância é dado, não erro. Protocolo: (1) Ouvir a discordância sem
defensividade. (2) Explorar: "Em que contexto você se vê diferente?" — isso
frequentemente revela que o respondente está pensando em um contexto específico
enquanto o instrumento captura tendência geral. (3) Se a discordância persistir,
registrar no relatório como "resultado contestado pelo respondente" com a
explicação fornecida. (4) Nunca alterar scores para agradar — mas sempre
contextualizar.
